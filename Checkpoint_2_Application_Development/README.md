# Checkpoint 2 - Application Development

Galeria de atores e atrizes feita com HTML, CSS e JavaScript.

O site mostra os dados do arquivo `dados.js` em cards e permite pesquisar pelo nome enquanto digitamos.

## Como abrir

Abra o arquivo `index.html` no navegador, com os demais arquivos na mesma pasta.

## Arquivos

- `index.html`: estrutura da página e campo de pesquisa.
- `style.css`: visual dos cards e organização em grid.
- `dados.js`: dados fornecidos pelo professor (sem alterações).
- `script.js`: mostra os cards e faz o filtro com `oninput`, `filter()` e `includes()`.
- `sem-foto.svg`: imagem de reserva quando a foto da internet não carregar.
- `prints/`: capturas da tela inicial e da busca.

As fotos vêm de links na internet e, por isso, precisam de conexão para aparecer. Caso não carreguem, aparece uma imagem de reserva.
